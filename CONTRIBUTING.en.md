# Contributing

**Languages / Langues:** 🇬🇧 English · 🇫🇷 [Français](CONTRIBUTING.md)

Thank you for your interest!

- Open an issue describing the problem, environment and expected result.
- Keep changes small and reviewable, with examples, tests when practical, and updated documentation.
- **Never commit** passwords, tokens, private organizational IP addresses, real usernames, customer logs, or sensitive configurations.
- Test any changes to Windows, Active Directory or Linux in a lab before suggesting production use.
- If you add a new feature or change documented behavior, update both the French and English README files.
