# Contributions

**Langues / Languages :** 🇫🇷 Français · 🇬🇧 [English](CONTRIBUTING.en.md)

Merci pour votre intérêt !

- Proposez une issue décrivant le problème à résoudre, l'environnement et le résultat attendu.
- Fournissez de petits changements révisables accompagnés d'exemples, de tests lorsque c'est possible, et d'une mise à jour du README.
- **Ne publiez jamais** de mots de passe, tokens, IP privées d'une organisation, noms d'utilisateurs réels, logs clients ou fichiers de configuration sensibles.
- Testez toute action modifiant Windows, Active Directory ou Linux dans un environnement de laboratoire avant de proposer son usage en production.
